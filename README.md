# GRC / Privacy / AI Security Projects

These projects were built as independent portfolio case studies to show how hands-on cybersecurity work can connect to governance, risk management, data protection and AI security.

## 01 , Cybersecurity & Data Governance Assessment

**Technical security → risk → NIS2-oriented controls → ownership → remediation**

Includes:
- company and scope definition
- asset/data inventory
- data-processing register
- Wazuh and Suricata evidence mapping
- risk methodology
- risk register
- NIS2-oriented control mapping
- control maturity
- remediation backlog
- residual risk and risk acceptance

## 02 , AI Privacy & Security Risk Assessment

**AI use case → data flow → privacy/security risk → controls → residual risk**

Includes:
- architecture/data-flow model
- DPIA-style assessment
- privacy and AI security risks
- privacy-by-design controls
- risk register
- governance considerations
- small Python PII-masking and prompt-injection detection PoC

All company details and assessment values are illustrative. These projects are not legal opinions or formal compliance certifications.
