# Network Security Evidence

This evidence is linked to the Network Security Monitoring & Detection Lab already in the portfolio.

## Lab evidence

- Nmap for host/service discovery
- Wireshark for packet investigation
- Suricata for network detection
- Custom ICMP and TCP SYN detection rules
- Python alert analyser

## Governance translation

`Network alert → affected asset → investigation → security risk → monitoring/control requirement → owner → remediation`

The lab is not presented as evidence from a real company. It is hands-on portfolio evidence used to demonstrate the technical side of the assessment.
